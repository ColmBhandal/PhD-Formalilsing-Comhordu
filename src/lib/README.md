# lib/: general tools

General tools that know nothing about Comhordú. Nothing here imports from the other folders.

| File | What it holds |
|---|---|
| [`Extras/LibTactics.v`](Extras/LibTactics.v) | Arthur Charguéraud's LibTactics, a vendored collection of general-purpose tactics. |
| [`GenTacs.v`](GenTacs.v) | The project's own general tactics, such as eliminating conjunctions. |
| [`RInequalities.v`](RInequalities.v) | Lemmas and tactics for inequalities over the reals. |
| [`StandardResults.v`](StandardResults.v) | Results about real numbers, positions, distances and intervals. |
| [`GenBasics.v`](GenBasics.v) | Times, delays and distances, and helpers for natural numbers, lists and sets. |
